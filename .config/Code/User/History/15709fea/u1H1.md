# Conceptualmente, ¿que diferencia hay entre un procedimiento y una funcion? Responda. Ademas, dentro del lenguaje de Python, ¿como implementa ambos, en que se diferencian?

### 1. Diferencia Conceptual

La diferencia radica principalmente en el **objetivo** y el **resultado** de la rutina:

**Función (Function)**

- **Concepto:** Está diseñada para realizar un cálculo y devolver un valor al programa que la llamó.

- **Analogía:** Es como una calculadora; le das datos, procesa y te entrega un resultado que puedes guardar en una variable.

- **Propiedad:** Se espera que sea "determinista" (idealmente una función pura), donde su salida dependa de sus entradas.

Procedimiento (Procedure)

    Concepto: Es un conjunto de instrucciones que se ejecutan para realizar una tarea o acción específica, sin necesidad de devolver un resultado al programa.

    Analogía: Es como una receta de cocina; sigues los pasos para limpiar la cocina o imprimir un documento, pero no necesariamente obtienes un "valor" que puedas usar en una ecuación matemática.

    Propiedad: Suelen causar "efectos secundarios" (side effects), como mostrar algo en pantalla, modificar un archivo o cambiar el estado de una base de datos.
