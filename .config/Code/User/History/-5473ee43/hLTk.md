### Escriba un algoritmo que determina si un numero es par o impar. Utilice pseudo codigo.

```Pseudocodigo
ALGORITMO ParImpar
    VARIABLES:
        number: int
    INICIO
        SI number MOD 2 == 0 ENTONCES
            MOSTRAR "Es par"
        SINO
            MOSTRAR "Es impar"
        FIN_SI
    FIN
```
