### Realizar modificaciones para el ejercicio anterior para que permita variantes en las tarjetas de credito ingresadas, Visa, Master, American Express con recargos en 5%, 7% o 9% respectivamente sobre el valor de la compra.

```Pseudocodigo
Algoritmo Descuento_Recargo_Extendido
    Definir monto, monto_final Como Real
    Definir forma_pago Como Entero

    Escribir "Ingrese el monto de la compra:"
    Leer monto

    Escribir "Seleccione forma de pago:"
    Escribir "1 - Débito (10% desc)"
    Escribir "2 - Efectivo (13% desc)"
    Escribir "3 - Tarjeta Visa (5% recargo)"
    Escribir "4 - Tarjeta Mastercard (7% recargo)"
    Escribir "5 - Tarjeta American Express (9% recargo)"
    Leer forma_pago

    Segun forma_pago Hacer
        1: monto_final <- monto * 0.90
        2: monto_final <- monto * 0.87
        3: monto_final <- monto * 1.05
        4: monto_final <- monto * 1.07
        5: monto_final <- monto * 1.09
        De Otro Modo:
            Escribir "Opción inválida"
            monto_final <- monto
    Fin Segun

    Escribir "Total a cobrar: $", monto_final
FinAlgoritmo
```
