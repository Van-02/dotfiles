## ¿Algoritomo y programa son lo mismo? Defina y explique

### 1. ¿Que es un Algoritmo?

Es una secuencia logica, finita y definida de pasos para resolver un problema o realizar una tarea.

- **Es abstracto**: No depende de una computadora ni de un lenguaje de programacion
- **Es universal**: Un algoritmo para sumar dos numeros es el mismo en español, en ingles o en cualquier idioma
- **Caracteristicas**: Debe ser preciso, tener un inicio y un fin, y producir siempre el mismo resultado ante la misma entrada.

### 2. ¿Que es un Programa?

Es la implementacion de un algoritmo mediante un lenguaje de programacion para que una computadora pueda ejecutarlo.

- **Es concreto**: Esta escrito en codigo
- **Es dependiente**: Necesita un entorno para funcionar
- **Componentes**: Incluye el algoritmo, pero tambien la sintaxis del lenguaje, la gestion de memoria y la interfaz de usuario.
