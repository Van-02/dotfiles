## ¿Que tipos de datos definidos por el lenguaje de Python conoce?

Python es un lenguaje de **tipado dinamico**, lo que significa que no necesitas declarar el tipo de dato al crear una variable, pero internamente Python clasifica todo en categorias muy claras.

### 1. Clasificacion de Tipos de Datos

#### Numericos

- **int**: Numeros sin decimales
- **float**: Numeros con decimales
- **complex**: Numeros con parte real y una imaginaria

#### Secuencias

- **str**: Texto encerrado en comillas
- **list**: Colecciones ordenadas y mutables(se pueden cambiar)
- **tuple**: Colecciones ordenadas e inmutables
- **range**: Generador de secuencias numericas

#### Otros tipos fundamentales

- **bool**: Valores logicos True o False
- **dict**: Coleccion de pares clave-valor
- **set**: Coleccion de elementos unicos y sin orden
- **NoneType**: Representa la ausencia de valor (None)

## ¿Que tamaño permiten?

Aqui es donde Python se diferencia de lenguajes como C, C++ o Java.

En Python 3, los enteros tienen precision arbitraria. Esto significa que no existe un limite maximo fijo para un numero entero. El limite real es la memoria RAM disponible en tu computadora
